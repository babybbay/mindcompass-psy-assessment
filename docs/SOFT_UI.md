# MindCompass Soft UI

2026-09-12。本轮仅统一界面样式及站点图标配色，保留六个量表、评分、D1数据、管理员身份限制和知情同意流程。

## 统一规则

- `app/mindcompass.css`：共享主题和组件样式。背景为Slate 50，标题Gray 800，正文Gray 600；主色为低饱和靛紫`#625c98`。
- 卡片24px圆角、24/32px内边距、24/32px网格间距，页面区块64/96px留白，容器最大宽度1152px。
- 按钮16px圆角、至少48px高度、柔和有色阴影；悬停上浮，按下轻微缩放及内阴影，键盘焦点有柔光环。
- 图标采用圆形淡色底；输入、选项和复选框统一配色，并保留原生键盘语义。
- `app/globals.css`仅扫描实际页面和MindCompass组件，避免未使用组件的默认工具类进入构建产物。
- `public/favicon.svg`沿用已有图形，改为主题紫色。

## 冲突取舍

禁止项优先。不使用任意值阴影类、渐变、纯黑、硬边框、玻璃态或嵌套卡片。以较深正文确保对比度；彩色区域使用深紫或白字。阴影使用透明度和模糊，非无模糊投影。禁用按钮保留可读文本。动效采用200/300ms ease-in-out，并响应减少动画偏好。

## 验证范围

`tests/e2e/soft-ui.spec.ts`检查禁止项、必要样式、首页与六入口在320/768/1440px的布局、按钮圆角及鼠标悬停、键盘焦点、减少动画规则、问卷/结果/隐私/反馈/未登录后台及本地授权后台的可见文字对比度。问卷与结果分别按390px和1440px核验，后台按768px核验。文字对比度检查阈值统一为4.5:1。

修复构建CSS压缩器合并transform与translate重置时丢失独立位移重置的问题；减少动画测试针对构建后的页面执行。触控环境不要求持续鼠标悬停，桌面环境验证上浮状态。

完整功能回归继续使用`npm run test:e2e`；评分和本地数据库回归使用`npm test`；另执行`npm run typecheck`、`npm run lint`、`npm run check:security`与`npm run build`。所有模拟回答仅写入隔离本地测试库。

自动检查不等于完整WCAG认证。仍需真人在iOS Safari、Android浏览器及屏幕阅读器上体验，尤其检查长量表、后台横向表格滚动和系统字体差异。截图位于被忽略的`work/soft-*.png`，不纳入生产数据或构建。
