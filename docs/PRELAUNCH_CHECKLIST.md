# 上线前人工检查清单

本清单未勾选项不代表完成；自动化合成数据不等于真实参与者。用于正式邀请前及试用后的复核。

## 来源与研究责任

- [ ] 负责人确认非商业教育／研究用途，提供真实的公开联系方式。
- [ ] 逐题对照BFI-2中文版附录，复核60题、30道反向题、五维和十五子维度。
- [ ] 由独立双语审核者核对TriPM中文辅助译文，记录回译差异；未完成前保留探索性标签。
- [ ] 明确当前爱情问卷不是LAS-42；如需要正式LAS-42，取得指定版本及许可后另建版本。
- [ ] 审阅原创题目的歧义、社会赞许性、双重问题、反向措辞和适用情境。
- [ ] 确认不将结果用于诊断、治疗、人员筛选或其他高风险决策。

## 隐私与部署

- [ ] 核实管理员认证不再信任任何身份请求头：伪造oai-authenticated-user-id不得访问/admin或管理API（有自动化测试与上线复测）。
- [ ] 使用管理密码完成真实登录与登出；未登录、错误密码访问管理API均失败。
- [ ] 确认生产ADMIN_PASSWORD仅在服务端秘密环境变量（或deploy-config.json，已gitignore）中，未进入浏览器、数据库、日志或Git。
- [ ] 核实D1存储地域、托管日志字段、访问权限与日志／备份保留政策。
- [ ] 确认每日保留期清理触发器实际生效；本地构建包含UTC 18:00计划，但不能用构建配置代替线上执行证据。
- [ ] 完整测试撤回、单次清除、过期处理；确认旧版数据库无未经批准的删除或迁移。
- [ ] 为匿名导出文件设置访问权限和180天内的删除期限，分享报告不包含逐人答卷。
- [ ] 在实际手机浏览器、桌面浏览器和辅助技术下检查焦点、对比度与页面缩放。

## 10名真实参与者试用

- [ ] 招募10名确已满18岁的真实志愿者；先告知目的、数据用途、退出方式与结果局限。
- [ ] 每人由自己勾选同意并作答；不得由AI代填、克隆答卷或补造完成时间。
- [ ] 覆盖六种测评、不同设备、首次进入和中途恢复。每位不必被迫完成所有量表。
- [ ] 记录真实的匿名试用编号、使用设备类别、成功／失败情况、实际耗时、疑惑题号、操作问题与原话摘要。
- [ ] 自由反馈不要包含姓名、邮箱、手机号、班级、详细住址或可识别截图；报告引用前人工去标识化。
- [ ] 使用`PILOT_EVALUATION_TEMPLATE.md`填写实际观察，未参与者保持空白。
- [ ] 针对每个问题记录修复、复测结果和未解决原因；保留真实证据的来源与日期。
