# MindCompass 评分说明

版本：2026-09-12。规范来源是 `lib/assessment` 下的配置。服务端按数据库中冻结的量表版本计分；浏览器不能提交最终得分。保留原始选项与校正后分数，不原地改写原始作答。

## 通用规则

- 五点题：正向分 = 原作答；反向分 = 6 − 原作答。1→5、2→4、3→3、4→2、5→1。
- 每题只属于一个叶子维度。BFI-2 的叶子是15个子维度；上级维度只聚合其三个子维度的所属题目，不重复计数。
- 默认等权均分 = 校正分之和 / 所属题数。存储未四舍五入结果，页面显示一位小数。
- 草稿允许漏答，但任何漏答均阻止正式计分。没有插补、按剩余题目折算或隐含0分。
- 没有常模或高低诊断阈值；`thresholds: null`。图形长度仅指量尺内位置，不是百分位。
- 总分只在量表原协议明确要求时保留；不同维度的均分不自动合并成总分。

## TriPM 原版例外

配置：`lib/assessment/tripm.ts`。依据用户后续明确指定的公开原版，保留58题与四级选项，覆盖最初统一五点的要求。

- True=3，Somewhat true=2，Somewhat false=1，False=0。
- 反向为 **3 − 原作答**，不能使用6−原作答，也不能将五点结果线性伪装为原版分数。
- 反向题：2,4,10,11,16,21,25,30,33,35,39,41,44,47,50,52,57。
- 大胆性：1,4,7,10,13,16,19,22,25,28,32,35,38,41,44,47,50,54,57；19题，总分0–57。
- 冷酷倾向：2,6,8,11,14,17,20,23,26,29,33,36,39,40,42,45,48,52,55；19题，总分0–57。

- 原版总和为三个维度总和，范围0–174，只作计分记录，不用来分类或判断风险。

英文原题保留；中文是项目辅助译文，未完成独立双语回译和中文样本验证。不能称作标准化中文TriPM，不能把原版的验证结果直接移用到本网站的中文施测。

## 爱情态度与三项自编问卷

配置：`lib/assessment/exploratory.ts`。

- 爱情态度42题：激情、游戏、友伴、现实、依恋不安、关怀付出，每维7题，均分1–5，无总分。依据Lee六取向框架新编，**不是LAS-42原题或译本**。未核实LAS-42中文版许可，不能与LAS文献得分比较。
- AI态度12题：采纳意愿、风险担忧、审慎使用各4题；各维均分1–5，无总分。风险担忧不能简单等同于不采纳。
- 冒险倾向12题：社交表达、新体验、任务不确定性各4题；不作高风险行为决策建议。
- 团队合作12题：沟通协调、责任投入、分歧协商各4题；不作人员筛选。
- 自编配置中的 `R:` 标记在构造配置时变为明确的 `reverse` 布尔值；题面不显示反向标记。构念结构均为设计假设，待认知访谈和研究验证。

## 旧版与统计

`lib/assessment/legacy.ts` 保留第一版28题及反向键。修复原来的早期四舍五入和无依据高低分段；新增同意、会话、版本和服务端计分。旧 `responses` 表保持不变，不追填同意或参与编号，不与新版本合并。原数据库可能包含试验记录，未核实来源。

维度均值和分布采用每参与者、每量表版本首个完成记录。完成率=已完成次数/全部开始次数，包含仍在作答、退出和过期记录，且注明截止时点。撤回并删除整个参与者后，该参与者不再纳入统计。平均耗时使用完成时间减开始时间，包含中途离开，不声称为有效作答时长。零样本均值和完成率为null，不是0或100%。

接口只接受量表允许的题号和选项；保存以revision进行乐观并发控制。最终答案、分数与完成状态在一条条件UPDATE中原子写入；相同的完成请求可重试，不能改写已经完成的结果。不同量表与不同参与者通过外键与服务端归属检查隔离。
