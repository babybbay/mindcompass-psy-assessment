# MindCompass技术报告（初稿）

日期：2026-09-12。支持教育与研究探索，验证产品可用性与计分实现，不是临床工具或量表效度研究结论。

## 原系统与架构

原系统是React19、TypeScript、Vinext/Vite、Sites/D1的28题单页应用。前端计分、后端接收固定六得分，管理固定码公开，草稿内存保存。

本轮保留技术栈、旧题、旧表与部署项目，增加六问卷独立路由、服务端评分、D1逐题保存。先验证同意、来源、会话、量表与版本，再处理数据；管理依赖平台验证身份和服务器白名单。

数据流：知情同意与成年确认 → 随机参与编号／安全Cookie → 六问卷选题 → 版本快照与独立答卷 → D1保存与修订号 → 服务端完整性校验和评分 → 本人结果图表／受限管理统计。

新建mc_participants、mc_consents、mc_scale_versions、mc_attempts、mc_feedback。答案、分数和状态在同一行条件更新，以避免部分完成；participantId关联多量表，attemptId区分重测。令牌只存哈希，无身份字段。responses保留且与新数据隔离。

## 测量规则

BFI-2中文版60题、五领域和15子维度按论文附录。TriPM英文原版58题四点0–3，中文为未独立回译的辅助译文。实际爱情态度为原创42题探索，不能称标准LAS-42。AI、冒险和团队合作各12题原创探索。

五点反向6−原值；TriPM反向3−原值。维度只聚合所属题，正式结果要求完整回答。没有常模、排名、诊断阈值或医疗建议。规则、键和许可见SCORING.md、SCALE_SOURCES.md与lib/assessment。

## 质量保证

评分测试覆盖反向极值、维度映射、BFI全中点、TriPM量尺／总和、旧舍入回归。真实SQLite执行迁移和接口SQL，覆盖六量表、隔离、重试、修订冲突、漏答拒绝、伪造分数拒绝、授权、清理、撤回和关闭重开。

浏览器连接本地Worker和隔离持久化D1，在1440和390像素宽度完成六问卷；检查刷新、前后导航、继续、独立结果、BFI子维度展开及正常流程无控制台错误，另测键盘、故障保存重试与旧28题。最终命令和结果见DELIVERY.md。

本地模拟可信管理员请求头只验证应用白名单，不能证明生产OAuth和网关安全。未覆盖实际iOS／Android浏览器、人工屏幕阅读器、压力与渗透测试、平台日志或备份。故障测试预期503单独处理，不混入正常流程错误断言。

## 统计解释

均值／分布取每参与者每版本首份完成记录；导出保留全部重测并标识。完成率使用全部开始次数，退出和过期保留分母，无样本不生成均值。耗时包括暂停，不作为认知速度或注意力判断。旧数据只重算可验证回答，记录数不等于真实独立人数。未实现alpha／相关，10人试用不构成效度验证。

## 上线依赖

缺少经本人确认的本站管理员ID时后台锁定。实际每日调度、真实联系渠道、托管地域、日志与备份策略、许可和译文质量须核验。导出文件脱离应用清理机制，研究者另行管理。有限敏感模式扫描不证明基础设施或历史文件无敏感内容。
